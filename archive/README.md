| 파일 | 내용 |
|---|---|
| `episodes-2026-11-14.json` | 스키마 0.4.0에서 없앤 회차 정보 (배역별 담당 회차·게임 패치 범위 957건, 캐릭터 첫 등장 회차 674건). 검증을 거쳐 `data/`에 들어 있던 값. 캐릭터는 이전·새 ID와 원어 표기, 성우는 내부 ID와 원어 표기, 출처 URL 포함 |
| `episodes-2026-11-14-staging-bleach.json` | 같은 정보 중 당시 조사 중이던 블리치 스테이징 데이터 (배역 391건, 첫 등장 371건). **검증 전 값**이고 일부는 1차 검증에서 오류로 지적됨 |
